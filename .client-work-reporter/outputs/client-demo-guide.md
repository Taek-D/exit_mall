## 테스트 계정

|---|---|---|
| 고객 화면 | user@demo.com | demo2345 |
| 관리자 화면 | admin@demo.com | demo1234 |

관리자 화면과 고객 화면을 서로 다른 브라우저, 또는 시크릿 창으로 각각 열어두시면 주문 접수와 처리 흐름을 가장 보기 좋게 확인하실 수 있습니다.

---

### 1. 고객이 상품을 주문하는 흐름

고객 계정으로 로그인한 뒤 아래 순서로 확인해보시면 됩니다.

`/shop` → 상품 담기 → `/cart` → `/checkout` → 주문하기

주문이 완료되면 고객 예치금이 자동으로 줄어들고, 주문 내역에서 방금 만든 주문을 확인할 수 있습니다.

### 2. 상품별 1인 구매 한도 확인

상품 화면에서는 상품마다 구매 가능한 수량 제한을 확인할 수 있습니다. (고객은 확인 불가)

이미 구매한 수량이 있으면 남은 구매 가능 수량이 반영됩니다.
운영자가 특정 상품을 한 고객이 너무 많이 사지 못하도록 제한하는 용도입니다.

### 3. 고객 주문이 관리자에게 보이는 흐름

관리자 계정으로 로그인한 뒤 `/admin` 대시보드를 열어두고, 고객 화면에서 주문을 넣어보세요.

새 주문이 들어오면 관리자 화면에서 바로 확인할 수 있고, `/admin/orders`에서 주문 목록과 상태를 볼 수 있습니다.
주문 목록은 상태별로 나눠 볼 수 있고, 필요한 경우 엑셀로 내려받을 수 있습니다.

### 4. 관리자의 배송 처리 흐름

관리자 화면에서 아래 순서로 확인해보시면 됩니다.

`/admin/orders` → 주문 클릭 → 준비중 처리 → 발송 처리 → 배송 완료

발송 처리 단계에서는 택배사와 송장번호를 입력합니다.
CJ대한통운 주문은 주문 상세 화면에서 배송 상태를 바로 조회할 수 있고, 다른 택배사는 외부 배송조회 화면으로 연결됩니다.

### 5. 고객의 주문 내역과 주문 취소

고객 화면의 `/orders`에서 본인 주문 내역을 확인할 수 있습니다.

아직 처리 전인 주문은 고객이 직접 취소할 수 있습니다.
송장번호가 입력된 주문은 배송조회도 확인할 수 있습니다.

### 6. 신규 회원 가입 승인 흐름

새 브라우저나 시크릿 창에서 `/signup`으로 새 계정을 만들어보세요.

가입 직후에는 바로 쇼핑몰을 이용할 수 없고, "관리자 승인 대기" 상태로 막힙니다.
관리자 화면의 `/admin/approvals`에서 승인 또는 반려를 처리하면, 승인된 회원만 몰을 이용할 수 있습니다.

### 7. 예치금 충전 요청과 확인 흐름

고객 화면에서 아래 순서로 진행해보세요.

`/deposit` → 잔액과 요청 내역 확인 → `/deposit/new` → 금액과 입금자명 입력 → 이체 완료 요청

이후 관리자 화면의 `/admin/deposits`에서 확인 버튼을 누르면 고객 예치금에 금액이 반영됩니다.
입금이 맞지 않으면 관리자가 반려할 수도 있습니다.

### 8. 엑셀 주문서 업로드와 관리자 검토

고객 화면의 `/orders/upload`에서 엑셀 양식을 내려받아 주문서를 올릴 수 있습니다.

관리자는 `/admin/order-uploads`에서 업로드된 주문서를 확인하고, 원본 파일도 내려받아 검토할 수 있습니다.
승인하면 예치금이 차감되고 정식 주문으로 생성됩니다.
반려하면 반려 사유가 고객에게 보입니다.

### 9. 상품 등록과 운영 설정

관리자 화면의 `/admin/products`에서 상품을 등록하거나 수정할 수 있습니다.

상품 이미지 등록, 판매 여부, 재고, 가격, 상품별 1인 구매 한도까지 관리할 수 있습니다.
`/admin/settings`에서는 고객에게 보여줄 입금 계좌와 안내 문구를 설정할 수 있습니다.

### 10. 고객 관리와 잔액 관리

관리자 화면의 `/admin/users`에서 고객 상태와 예치금을 관리할 수 있습니다.

고객별 예치금 조정이 가능하고, 잔액 부족 기준도 설정할 수 있습니다.
잔액이 기준보다 낮은 고객은 `/admin/low-balance`에서 따로 볼 수 있어 충전 안내가 필요한 고객을 빠르게 찾을 수 있습니다.

## 아직 초안 단계로 봐주시면 좋은 부분

- 실제 상품 가격 정책과 노출 방식은 확정 후 더 맞출 수 있습니다.
- CJ대한통운 외 택배사의 앱 안 조회는 아직 확장 전입니다. 현재는 외부 조회 화면으로 연결됩니다.
- 배송조회 결과를 저장하거나, 배송완료 상태를 자동으로 바꾸는 기능은 아직 들어가 있지 않습니다.
- 대량 운영 전에는 실제 운영 계좌, 안내 문구, 상품 데이터, 배송 정책을 한 번 더 맞추는 과정이 필요합니다.

## 확인 요청드리고 싶은 부분

1. 고객이 상품을 보고 주문하는 흐름이 실제 운영 방식과 잘 맞는지
2. 예치금 충전 요청과 관리자 확인 방식이 불편하지 않은지
3. 주문 상태 이름과 배송 처리 단계가 현장 표현과 맞는지
4. 상품별 구매 한도 설정이 필요한 운영 방식과 맞는지
5. 엑셀 주문서 업로드가 실제 대량 주문 방식에 맞는지
6. 관리자 화면에서 자주 봐야 할 정보가 더 필요한지
7. 고객에게 보여줄 계좌 안내와 공지 문구를 어떻게 다듬으면 좋을지

확인해보시고, "이 화면은 이렇게 바꾸면 좋겠다" 싶은 부분만 편하게 말씀주시면 다음 단계에서 바로 반영해보겠습니다.
