# 예치금 기반 승인 후 차감

## 상황

고객이 상품을 요청하는 시점과 운영자가 실제로 거래를 확정하는 시점 사이에 재고, 잔액, 운영 검토가 달라질 수 있다. 요청 즉시 차감하면 반려나 운영 보류 때 환불·복구가 잦아지고, 승인 시점만 보면 고객에게 가용 잔액 안내가 늦어진다.

## 결정

고객 요청 시점에는 검토대기 주문을 만들고 가용 예치금에서 예약액으로만 보여준다. 실제 예치금 차감, 마스터 재고 차감, 고객 보유 재고 적립은 관리자 승인 시점에 한 번에 수행한다.

## 대안

요청 즉시 예치금을 차감하는 방식은 고객 잔액을 강하게 확보할 수 있지만, 반려·취소 때 환불 거래가 매번 필요하고 운영자가 아직 확정하지 않은 요청이 실제 회계처럼 보인다.

예치금을 전혀 예약하지 않는 방식은 단순하지만, 고객이 여러 검토대기 주문으로 잔액을 초과해 요청한 뒤 승인 시점에 대량 실패가 발생할 수 있다.

## 영향

가용 예치금 계산은 검토대기 상품 구매 금액을 빼야 한다. 승인 RPC는 승인 직전 잔액과 재고를 다시 검사해야 한다. 반려와 고객 검토대기 취소는 예치금 거래 기록을 만들지 않는다.
