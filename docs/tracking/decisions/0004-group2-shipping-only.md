# 2그룹 배송대행 전용 권한

## 상황

모든 고객이 엑시트몰 상품 구매와 예치금 흐름을 쓰는 것은 아니다. 일부 고객은 사입재고 입고와 배송대행만 필요하며, 상점·주문·예치금 화면에 접근하면 운영 범위와 맞지 않는 요청이 생길 수 있다.

## 결정

1그룹은 전체 기능을 사용하고, 2그룹은 사입재고 배송대행, 입고리스트, CS 문의, 가이드, 계정만 사용한다. 2그룹은 메뉴, 라우트, 주요 서버 액션에서 상점·주문·예치금·엑시트몰 배송대행을 차단한다.

## 대안

역할을 관리자와 사용자만 두는 방식은 단순하지만, 배송대행 전용 고객의 화면과 서버 권한을 분리할 수 없다.

기능별 권한 테이블을 두는 방식은 유연하지만, 현재 운영 범위에는 과하고 승인 화면에서 실수할 여지가 늘어난다.

## 영향

새 고객 기능은 2그룹 허용 여부를 명시해야 한다. 허용되지 않은 기능은 메뉴에서 숨기는 것만으로 부족하며, 미들웨어와 서버 액션에서도 막아야 한다. 그룹 값이 비어 있는 기존 사용자는 1그룹으로 취급해 백필 누락으로 차단되지 않게 한다.
