# 현재 배송대행 상품명 매칭

## 상황

배송대행 양식은 고객이 작성하는 엑셀이고, 현재 운영에서는 상품명과 옵션명이 고객과 운영자 모두에게 가장 직접적인 식별자다. 내부 UUID나 관리코드를 고객에게 강제하면 양식 작성 부담이 커진다.

## 결정

엑시트몰 배송대행은 현재 상품명으로 엑시트몰 상품 또는 사용자 수기 재고를 찾는다. 사입재고 배송대행은 상품명과 옵션명을 함께 사용한다. 중복되어 하나로 정할 수 없는 경우 업로드를 막고 운영 데이터 정리를 요구한다.

## 대안

내부 상품 ID를 양식에 넣는 방식은 매칭이 정확하지만 고객이 사람이 읽기 어려운 값을 다뤄야 한다.

관리코드를 필수로 두는 방식은 운영 친화적일 수 있지만, 기존 상품과 수기 재고, 사입재고의 코드 체계가 완전히 정리되어 있어야 한다.

## 영향

운영자는 상품명 중복을 관리해야 한다. 매칭 실패 메시지는 어떤 이름이 문제인지 보여줘야 한다. 추후 식별자 기반으로 바꿀 수 있으므로 이 결정은 영구 정책이 아니라 현재 운영 방식으로 다룬다.
