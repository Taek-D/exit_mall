# 승인 후 고객 취소 금지

## 상황

승인 이후에는 예치금, 재고, 송장, 운영 처리 상태가 이미 바뀐다. 고객이 승인된 요청을 직접 취소하면 어떤 거래를 되돌릴지, 어떤 배송이나 재고를 복구할지 불명확해진다.

## 결정

고객 직접 취소는 검토대기 상태에만 허용한다. 승인 이후 취소나 되돌리기 기능은 만들지 않는다.

## 대안

승인 후 고객 취소 기능은 고객 자율성을 높이지만, 재고 복구, 예치금 보정, 배송 중단, 송장 무효화가 모두 같은 버튼에 묶여 위험하다.

관리자 롤백 버튼은 운영자에게 편할 수 있지만, 잘못 누르면 회계와 재고 감사 기록이 역방향으로 복잡해진다.

## 영향

승인 이후 조정이 필요하면 별도 운영 절차로 처리한다. UI는 승인 이후 고객 취소 버튼을 노출하지 않는다. 새 요구가 들어와도 단순 상태 되돌리기 버튼으로 구현하지 않는다.
