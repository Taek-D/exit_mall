# 결정 기록

| 번호 | 결정 | 현재 영향 |
| --- | --- | --- |
| 0001 | 예치금 기반 승인 후 차감 | 고객 요청과 실제 차감을 분리하고, 관리자가 승인한 시점에 예치금과 재고를 함께 바꾼다. |
| 0002 | 상품 구매와 배송대행 분리 | 상품 구매는 보유 재고 적립이고 실제 발송은 엑셀 배송대행 업로드로 처리한다. |
| 0003 | 배송대행 배송비 별도 정산 | 행당 3,300원은 안내 금액으로 두고 예치금에서 자동 차감하지 않는다. |
| 0004 | 2그룹 배송대행 전용 권한 | 일부 고객을 사입재고 배송대행 중심으로 제한하고 구매·예치금 흐름에서 분리한다. |
| 0005 | 승인 후 고객 취소 금지 | 승인 이후 되돌리기 기능을 제공하지 않고 운영 조정으로만 다룬다. |
| 0006 | 현재 배송대행 상품명 매칭 | 현 단계에서는 상품명 또는 상품명+옵션명으로 매칭하되, 추후 변경 가능성을 열어 둔다. |
