# 미해결 사항

## 현재 확인된 미해결 문제

현재 즉시 기록해야 할 미해결 문제는 확인되지 않았다.

## 주의해서 다시 볼 수 있는 영역

배송대행 상품명 매칭은 운영 데이터 품질에 의존한다. 중복 상품명이 많아지면 업로드 실패가 잦아질 수 있다. 현재는 운영자가 이름을 정리하는 방식으로 해결하고 있으며, 식별자 기반 매칭으로 바꾸려면 고객 양식과 기존 데이터 호환 방식을 먼저 결정해야 한다.

`README.md`와 `MASTER.md`는 유니코드 인코딩으로 읽어야 한글이 정상 표시된다. 인코딩이 깨진 상태에서 문서를 복사하면 잘못된 설명이 생길 수 있다.
