기능 패키지 마일스톤 정의서

엑시트몰 (ExitMall) — 개발 산출물 기반 견적서 첨부용
작성 기준: 2026-05-16 총 7개 패키지 마이그레이션 55개 서버 액션 65개+ 페이지/컴포넌트 91개
프로젝트 개요

엑시트몰은 재고 위탁·배송대행 전문 B2B 플랫폼입니다. Next.js 14 + Supabase 풀스택 구조로, 2026년 4월 22일부터 약 24일간 단계적으로 구현되었습니다. Git 커밋 이력, DB 마이그레이션 타임라인(55개), 서버 액션 목록(65개+), 컴포넌트 구조(91개)를 교차 분석하여 클라이언트가 이해할 수 있는 7개 기능 패키지로 정리하였습니다.

기능 패키지 상세
P1 기반 인프라 & 인증 시스템 Phase 1
구현 날짜
2026-04-22
포함 기능
  • Next.js 14 + Supabase 프로젝트 초기 셋업 (배포: Vercel)
  • DB 초기 스키마: 회원(profiles), 상품(products), 주문(orders), 잔액 원장, 예치금(deposit_requests)
  • Row Level Security(RLS) 보안 정책 전체 설계
  • 미들웨어 역할/상태 게이트 (admin / 일반회원 / 승인대기 분기)
  • 회원가입 · 로그인 · 로그아웃 · 승인 대기 페이지
  • 비밀번호 변경 · 분실 이메일 재설정 · 아이디 찾기
  • 반려 회원 재신청 허용 로직
  • Zod 기반 공통 유효성 검사 + 한국어 에러 메시지 전체 적용
파일 수
약 28개
핵심 가치
이 패키지 없이는 서비스 자체가 존재하지 않음 — 로그인·보안·DB 모두 이 위에서 동작
P2 쇼핑몰 & 충전/결제 시스템 Phase 1
구현 날짜
2026-04-22
포함 기능

  • 결제 (예치 잔액 차감, 가용/예약 분리 표시)
  • 주문 내역 · 개별 주문 취소
  • 예치금 충전 신청 · 충전 내역 조회
  • 저잔액 경고 배너 (임계값 기반 자동 노출)
  • 관리자: 충전 승인/반려, 대시보드 잔액 통계
파일 수
약 22개
핵심 가치
이 패키지 없으면 수익이 없음 — 구매·충전이 모두 여기서 처리됨
P3 관리자 백오피스 Phase 1
구현 날짜
2026-04-22
포함 기능
  • 관리자 대시보드 (주문 수, 대기 건수, 잔액 부족 회원 집계)
  • 회원 목록 · 상세 · 상태(활성/정지) 변경 · 그룹 변경
  • 회원 가입 승인/반려 (그룹 선택 포함)

  • 주문 상태 관리 (준비중 → 발송 → 배달완료 → 취소)
  • Realtime 알림 (Supabase 채널 — 신규 주문·업로드 토스트)
  • 서비스 전역 설정 (저잔액 임계값 등)
  • 잔액 부족 사용자 전용 목록 페이지

약 36개
핵심 가치

P4 재고 관리 & 배송대행 시스템 Phase 2
구현 날짜
2026-05-06 ~ 05-08
포함 기능
  • 재고 주문(stock_orders): 장바구니 → 재고 적립 요청/승인/반려/취소
  • 사용자 보유 재고(user_inventory): 가용/예약 분리, 입출 이력 타임라인
  • 배송대행 업로드 (CJ 엑셀 양식 파서 + 헤더 별칭 지원)
  • 관리자 배송대행 처리: 승인/반려 + 송장번호 재업로드 + 완료 처리
  • CJ 택배 배송 조회 연동 (실시간 DeliveryTrackingLookup)
  • 송장 엑셀 다운로드 (고객용 행별 송장 확인)
  • 재고 수동 조정 UI (관리자 — 회원 상세 내 조정)
  • 주문 엑셀 업로드 (대량 주문 파일 업로드·검토·승인)
파일 수
약 34개
핵심 가치
이 패키지 없으면 배송 흐름이 멈춤 — 재고 적립부터 배송 완료까지 전체 사이클이 여기에 의존
P5 상품 대량 등록 & 커스텀 재고 Phase 3

2026-05-11 ~ 05-13

약 22개

P6 입고 요청 게시판 Phase 3
구현 날짜
2026-05-12 ~ 05-13
포함 기능
